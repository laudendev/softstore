Pop Focus 0.1.21 is out. If you use Pop Focus, please install this
version once by hand.

Starting with 0.1.21, the list of updates that Pop Focus checks is
signed with a hardware security key instead of a key stored on a
computer. This makes it much harder for anyone to pass off a fake
update as ours.

Versions 0.1.20 and earlier cannot read the new signed list. In
versions 0.1.14 to 0.1.20, Check for updates (Settings > Updates) now
shows "release list rejected: the update information is not signed by
us." Nothing is wrong with your copy of Pop Focus. It needs to be
updated by hand this one time.

What to do

1. Go to https://popfocus.lauden.dev/download/
2. Download the installer for your computer and install it over your
   current version:
   - Windows: run the setup .exe. You do not need to uninstall first.
   - macOS: open the .dmg and drag Pop Focus to Applications,
     choosing Replace.
   - Linux: install the .deb or .rpm over the current package.
3. Open Pop Focus. Your settings, calendars and license stay as they
   are.

After that, updates install from Settings > Updates again, with one
click.

Also new in 0.1.21: bubble text is larger and centred, sized to fit
every bubble shape and size, and Settings now says "events" for what
is on your calendar. Full list: https://popfocus.lauden.dev/changelog

If anything does not go as described, reply to this email.
